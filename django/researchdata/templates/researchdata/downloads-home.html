Database template spreadsheet

The database template spreadsheet is an Excel file containing a worksheet for each table in the database. Each worksheet includes a single header row for all fields within that table. This template spreadsheet can be used to record data if the live database is ever unavailable, e.g. if you're working offline. Then when you're able to access the live database again (e.g. when you have an internet connection) you can input the data from this spreadsheet into the database.
